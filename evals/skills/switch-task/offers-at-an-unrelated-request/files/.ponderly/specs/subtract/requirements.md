# Requirements Document

## Introduction

The calculator gains a subtract operation, so that a user can take one number from another with the same module that already adds and multiplies.

## Glossary

- **System**: The calc package.

## Requirements

### Requirement 1: Subtract two numbers

**User Story:** As a user of the calculator, I want to subtract one number from another, so that I do not work the difference out by hand.

#### Acceptance Criteria

1. WHEN a user calls subtract with two numbers, THE System SHALL return the first minus the second.
